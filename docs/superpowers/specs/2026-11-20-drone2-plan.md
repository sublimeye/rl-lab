# Experiment 011 (planned): drone, part 2

Agreed with the user on 2026-11-20; not started yet (waiting for "go").

## What the user asked for

1. **CAPS**: smooth sticks by adding smoothness to the PPO loss (Mysore et al., ICRA 2021),
   not to the reward: a temporal term (the action now vs the action at the next state) and a
   spatial term (the action vs the action at a slightly perturbed state).
2. **A moving landing platform.**
3. **Moving obstacles to avoid**: birds, slow and fast.
4. **Simulated vision**: something like a real drone's camera and image analysis, simplified
   so millions of steps train in minutes to hours. Plan: a 1D "depth camera", N rays fanned
   in front of and below the drone, each returning distance and what it hit (pad, pillar,
   bird, water), with some noise, in place of exact positions.
5. **Early exploration of real hardware** (robot or drone + model + sensors), as notes, no
   purchase or build yet.

## How (calls made)

- **Vectorised simulator from the start**: every drone copy's state in numpy arrays, one step
  for all copies at once. Keep 010's one-at-a-time version as the reference and **compare the
  two** (steps per second, minutes to a trained pilot, same results).
- The browser port stays plain JS (one drone), checked against the numpy version with a
  parity fixture as before.
- **JAX / PureJaxRL**: only if training with vision takes hours. That needs a JAX copy of the
  simulator (float32, pure functions); the numpy float64 version stays the reference for
  parity and tests. GPU runs would go on a rented NVIDIA GPU, which needs the user's own cloud
  account; the user is fine with $10–20 a month.

## Comparisons for the post

- Vectorised vs one-at-a-time: throughput and wall-clock to the same result.
- CAPS vs plain PPO vs 010's stick penalty and speed limit: smoothness, landing rate, speed.
- Exact positions vs simulated vision: how much harder, how much slower to train.
- Robustness with birds and a moving pad.

## Outcome (2026-11-20)

- Vectorised fleet: identical to post 10 bit for bit; raw stepping 7–17× faster; PPO training on
  post 10's task 2.4× faster (4.3 → 1.8 min), now limited by PPO's learning step. No JAX.
- Camera: 32 rays all round except a 60° cone up (widened from ±100° after pilots).
- Exact-position pilots land 165–180 of 200, camera pilots 147–152 (wind, payload, birds,
  moving pads, battery, noise and delay).
- CAPS (0.3, 0.3): sticks 6–9× calmer; 16–43 fewer landings in rough air.
- Birds: no pilot learned to dodge (blindfold test); a bigger penalty, a near-bird cost and
  three-bird training didn't change it. Memory made no difference.
